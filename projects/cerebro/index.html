Cerebro

A personal, plain-text second brain for mathematics, built around Org-mode and Org-roam with a pinned GNU Guix environment.

Scope
A long-lived, local-first system for mathematical notes and study workflows.
Work
Parametric LaTeX export, local graph queries, note consistency checks, and reproducible development tooling.
Tools
Emacs, Org-mode, Org-roam, GNU Guix, LaTeX, Make.
