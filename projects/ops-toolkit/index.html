ops-toolkit

Small Bash checks for certificates, disks, SSH keys, and backups that plug into existing monitoring.

Scope
Operational failures that often go unnoticed: expiring TLS certificates, full disks or inodes, weak or shared SSH keys, and stale backups.
Work
Four tools with a shared contract: Nagios-style exit codes and text, JSON, or Prometheus textfile output. Includes a Nix package and a NixOS module that runs checks on a timer.
Verification
bats tests with stubbed system commands, shellcheck, and a NixOS VM test that exports metrics through node_exporter.
Tools
Bash, OpenSSL, restic, Prometheus, Nix.
