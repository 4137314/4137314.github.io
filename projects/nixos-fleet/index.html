nixos-fleet

Composable NixOS modules and a repository template for managing company server fleets declaratively.

Scope
Server baselines for small and medium fleets: SSH, operator accounts, firewall, monitoring exposure, and backups.
Work
Modules under fleet.* (base, hardening, users, monitoring, backup) and a flake template with an inventory, roles, per-host files, and a deploy command.
Verification
A three-machine NixOS VM test checks key-only logins, sudo, refused root and password logins, exporter access limited to the monitoring network, account revocation, and a restic backup. The template's hosts are evaluated in CI.
Tools
NixOS, Nix flakes, nftables, fail2ban, restic, Prometheus exporters.
