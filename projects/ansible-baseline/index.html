Systems · Ansible

ansible-baseline

An Ansible collection that applies a production baseline to Debian, Ubuntu, and RHEL-family servers.

Scope
Existing servers that are not managed declaratively and need consistent access control, hardening, monitoring, and backups.
Work
Roles for operators with revocation, SSH and kernel hardening with unattended security updates, a single nftables ruleset, checksum-verified node_exporter, and restic with a systemd timer.
Verification
Molecule runs the full playbook on Debian 12 and Rocky Linux 9, checks idempotence, and verifies the effective SSH settings, firewall rules, metrics endpoint, and a real backup snapshot. ansible-lint runs with the production profile.
Tools
Ansible, Molecule, Docker, nftables, systemd, restic.
