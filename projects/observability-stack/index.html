Systems · Monitoring

observability-stack

Prometheus, Alertmanager, Grafana, Loki, and blackbox_exporter with tested alert rules, for Docker Compose or NixOS.

Scope
Alerting for host availability, disks, memory, failed services, HTTP endpoints, certificates, and backup freshness.
Work
Alert rules and routing with inhibition, file-based target discovery, a provisioned fleet dashboard, a pinned Compose stack, and an equivalent NixOS module that shares the same rules and dashboards.
Verification
promtool unit tests exercise the alert rules, amtool validates routing, a NixOS VM test starts the whole stack and checks scraping and dashboard provisioning, and CI smoke-tests the Compose deployment.
Tools
Prometheus, Alertmanager, Grafana, Loki, Docker Compose, NixOS.
